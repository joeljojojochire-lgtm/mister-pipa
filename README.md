# Mister Pipa Show

Party game para Telegram.

## Características
- Carrera multiplayer
- Sabotajes
- Votaciones
- Objetos
- Eventos aleatorios
- Economía

## Comandos

/crear
/unirse
/jugar

## Deploy

Render:
- Build Command:
pip install -r requirements.txt

- Start Command:
python bot.py

## Variable necesaria

TELEGRAM_TOKEN
